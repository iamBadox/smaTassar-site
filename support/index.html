Help with Små Tassar

Before troubleshooting

  1. Check that the device has a working internet connection if the problem involves Family Sync.
  2. Close and reopen Små Tassar, then return to Settings → Family Sync.
  3. Tap Sync Now and read any status message shown there.
  4. Export a backup before deleting the app or making major changes. Local data is not automatically restored after app deletion.

Family Sync says you are not signed in to iCloud

  1. Open the iPhone Settings app.
  2. Tap your name at the top and confirm that you are signed in to an Apple Account.
  3. Open iCloud and confirm iCloud services are available.
  4. Return to Små Tassar and tap Sync Now.

Family Sync is designed for people using different Apple IDs. The app never asks for or receives your Apple ID password.

A Family Sync join code does not work

  1. Ask the family creator to copy or share the current six-character code from Settings → Family Sync.
  2. Enter the code exactly as shown and check easily confused letters or numbers.
  3. Make sure both devices are online and signed in to iCloud.
  4. On the device that created the family, tap Sync Now, then try joining again.

Keep the code private. Anyone with the join code can join the family in the app. Never include it in a public support message.

Shared data is missing or out of date

  1. Open Settings → Family Sync on both devices and tap Sync Now.
  2. Confirm both devices show the same family and that the member list is current.
  3. Remember that existing local litters are shared only when someone explicitly chooses Share Existing Litters.
  4. Imported backups stay local and are not automatically uploaded to Family Sync.

Sync also runs when the app launches and when it returns to the foreground. It is not a live, instant messaging service.

Export a backup

  1. In Små Tassar, open Settings → Your Data.
  2. Tap Export Data.
  3. Use the iOS share sheet to save the JSON file somewhere you control, such as Files or AirDrop.
  4. Keep the file private if it contains names or details you do not want to share.

Import a backup

  1. Open Settings → Your Data.
  2. Tap Import Data and choose a Små Tassar JSON backup.
  3. Review the completion message. Existing records with the same identifiers are merged rather than blindly overwritten.
  4. If you want imported litters in Family Sync, share them explicitly after checking the import.

Contact

If these steps do not solve the problem, visit André B.'s public GitHub profile for current public contact options.

Include the app version, iOS version, the step that failed, and the exact error message. Do not post a Family Sync join code, exported backup, Apple ID, or other private information.

Svenska

Hjälp med Små Tassar

Innan du felsöker

  1. Kontrollera att enheten har en fungerande internetanslutning om problemet gäller Familjesynk.
  2. Stäng och öppna Små Tassar igen och gå sedan till Inställningar → Familjesynk.
  3. Tryck på Synka nu och läs statusmeddelandet som visas.
  4. Exportera en säkerhetskopia innan du raderar appen eller gör större ändringar. Lokal data återställs inte automatiskt efter att appen raderats.

Familjesynk säger att du inte är inloggad på iCloud

  1. Öppna appen Inställningar på iPhone.
  2. Tryck på ditt namn högst upp och kontrollera att du är inloggad på ett Apple-konto.
  3. Öppna iCloud och kontrollera att iCloud-tjänster är tillgängliga.
  4. Gå tillbaka till Små Tassar och tryck på Synka nu.

Familjesynk är utformat för personer med olika Apple-ID. Appen frågar aldrig efter och får aldrig ditt lösenord till Apple-ID:t.

En anslutningskod till Familjesynk fungerar inte

  1. Be den som skapade familjen att kopiera eller dela den aktuella sex tecken långa koden från Inställningar → Familjesynk.
  2. Ange koden exakt som den visas och kontrollera bokstäver eller siffror som är lätta att blanda ihop.
  3. Kontrollera att båda enheterna är online och inloggade på iCloud.
  4. Tryck på Synka nu på enheten som skapade familjen och försök sedan gå med igen.

Håll koden privat. Den som har anslutningskoden kan gå med i familjen i appen. Ta aldrig med den i ett offentligt supportmeddelande.

Delad data saknas eller är inaktuell

  1. Öppna Inställningar → Familjesynk på båda enheterna och tryck på Synka nu.
  2. Kontrollera att båda enheterna visar samma familj och att medlemslistan är aktuell.
  3. Kom ihåg att befintliga lokala kullar delas först när någon uttryckligen väljer Dela befintliga kullar.
  4. Importerade säkerhetskopior stannar lokalt och laddas inte automatiskt upp till Familjesynk.

Synkronisering sker också när appen startar och när den återgår till förgrunden. Det är inte en direktmeddelandetjänst i realtid.

Exportera en säkerhetskopia

  1. Öppna Inställningar → Din data i Små Tassar.
  2. Tryck på Exportera data.
  3. Använd iOS delningsmeny för att spara JSON-filen på en plats du kontrollerar, till exempel Filer eller AirDrop.
  4. Håll filen privat om den innehåller namn eller uppgifter som du inte vill dela.

Importera en säkerhetskopia

  1. Öppna Inställningar → Din data.
  2. Tryck på Importera data och välj en JSON-säkerhetskopia från Små Tassar.
  3. Läs slutförandemeddelandet. Befintliga poster med samma identifierare slås ihop i stället för att skrivas över utan kontroll.
  4. Om du vill ha importerade kullar i Familjesynk delar du dem uttryckligen efter att du kontrollerat importen.

Kontakt

Om stegen inte löser problemet, besök André B:s publika GitHub-profil för aktuella offentliga kontaktalternativ.

Ange appversion, iOS-version, vilket steg som misslyckades och det exakta felmeddelandet. Publicera inte en anslutningskod till Familjesynk, en exporterad säkerhetskopia, ett Apple-ID eller annan privat information.
